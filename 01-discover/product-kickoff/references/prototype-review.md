# 带联动旁注的原型

以本技能的交付文件名为准。Web 使用 `templates/web-review-template.html`，APP/H5 使用 `templates/mobile-review-template.html`。按 [需求提取](requirement-rules.md)、[Web 行为](prototype-rules.md) 或 [移动端行为](app-prototype-rules.md) 梳理任务、字段与状态，再按 [UI 设计规则](ui-design-rules.md) 确定布局和视觉方向。用户给出的品牌、组件与交付范围优先。可调用 `frontend-design` 或 `ui-ux-pro-max` 补充视觉设计。

## 页面与旁注

- 宽屏默认左侧约 80% 是可操作的产品界面，右侧约 20% 是浅色说明区，并给说明栏保留可读宽度。两侧独立滚动。窄屏上下排布，右侧卡片的定位入口仍可用。
- 按当前页面或关键状态挑选 2–5 个业务区块。左侧以唯一的 `data-review-target` 标识区块，右侧用同值的 `data-review-note` 标识说明卡。一个状态内每张卡对应一个区块。能按业务任务合并的字段放在同一张卡。
- 右栏逐卡写区域名、用途和适用的字段、操作或规则、权限、异常、验收。已有 PRD 时复用正式 R/AC 编号。产品规则有歧义时标明是演示假设。页面级完整说明可折叠在卡片之后。
- 使用模板自带 SVG 曲线和两端编号联动。鼠标停在区块或说明卡、或键盘聚焦其中的控件时，突出对应关系。点击卡片标题将左侧区块滚进视野。评审者可隐藏连线。
- 连线随页面、状态、两侧滚动和窗口尺寸变化重绘。不可见区块隐藏对应连线。图层不接收点击，业务表单、链接、弹窗保持可用。说明卡使用 `<button>`，不要把业务交互绑到曲线。

## 生成与验证

从终端模板复制出项目 HTML，再替换业务页面、模拟数据和当前状态的说明卡。模板已经内嵌评审样式和脚本，`assets/review-annotations.css` 与 `.js` 用于维护它们。成品是单文件，可以离线双击打开。

保留内联的 `<script id="review-annotations-script">` 和模板的旁注结构。只有 SVG 占位层时，浏览器不会绘制连线。Web 表单沿用模板的 `bindDemoForm`。按钮点击和 `submit` 事件调用同一个处理函数，并在入口阻止默认提交。这样预览框关闭 `allow-forms` 时，查询和保存仍由页面脚本处理，回车也可触发。

运行 `python scripts/validate_html.py <原型路径>`，并按 [交付自检清单](self-checklist.md) 在浏览器验证。离线直开和 `sandbox="allow-scripts"` 预览都测试查询、保存等主操作，分别覆盖按钮和键盘。宽屏确认实际绘出的连线随卡片定位、滚动、换页和窗口大小变化，窄屏保留卡片定位。移动端另验证状态切换和本地 HTML 导出。记录实际运行的场景和未验证的交互。
